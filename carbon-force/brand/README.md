# Your existing branding goes here

Nothing in this folder was created or changed by the app. It only reads it.

- **Logo:** save your existing logo as `logo.png` (or `logo.jpg`, `logo.svg`, `logo.webp`) in this folder.
  The command center shows it in the header. If there's no logo file, it shows the business name as plain text.
- **Flyers:** keep your existing flyer files in `brand/flyers/`. Several posts tell you to use the flyer
  as the image (Day 1 and Day 2).

The app never edits, resizes or replaces these files. To change the logo, swap the file yourself.
